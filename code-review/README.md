# 🎯 Simulador de Pull Requests - Code Review Training

Este espaço contém exercícios de code review para treinar habilidades profissionais de revisão de código.

## 📋 Exercícios Disponíveis

### 1️⃣ **Nível INICIANTE**
- **Arquivo**: `exercicio_01_iniciante.md`
- **Linguagem**: PHP
- **Contexto**: Validação de formulário de cadastro
- **Dificuldade**: Conceitos básicos, erros comuns

### 2️⃣ **Nível INTERMEDIÁRIO**
- **Arquivo**: `exercicio_02_intermediario.md`
- **Linguagem**: PHP
- **Contexto**: Serviço de autenticação com banco de dados
- **Dificuldade**: Segurança, padrões, performance

### 3️⃣ **Nível AVANÇADO**
- **Arquivo**: `exercicio_03_avancado.md`
- **Linguagem**: PHP
- **Contexto**: API REST com lógica complexa de negócio
- **Dificuldade**: Arquitetura, design patterns, edge cases

---

## 🔄 Como Usar

1. **Escolha um exercício** baseado no seu nível
2. **Leia a descrição do PR** e o código apresentado
3. **Faça sua revisão** adicionando comentários nas linhas específicas
4. **Quando terminar**, diga "finalizei a revisão"
5. **Receba feedback** completo com análise técnica e nota

---

## 📝 Formato de Comentários

Ao revisar, use o formato:

```
**Arquivo:** `caminho/do/arquivo.php`
**Linha:** XX

> Seu comentário aqui
```

---

## ✅ Critérios de Avaliação

Sua revisão será avaliada por:
- ✔️ Capacidade de encontrar bugs
- ✔️ Priorização dos problemas
- ✔️ Qualidade técnica dos comentários
- ✔️ Clareza da comunicação
- ✔️ Capacidade de identificar riscos

**Nota final**: 0 a 10
